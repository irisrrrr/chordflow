# ChordFlow — 安靜琴房｜吉他轉調與指法簡化工作站

> **Vibe Coding 互動網頁設計作品**  
> 一款專為吉他初學者與彈唱練習者打造的純前端互動和弦譜工作站。結合十二平均律自由轉調、智慧變調夾（Capo）試算、封閉大橫按一鍵簡化、真實比例 SVG 玫瑰木指板圖、阻尼正弦波琴弦物理動畫與 Web Audio 即時刷弦合成器。

## 一、發想動機與規格收斂過程

### 1. 痛點觀察
初學木吉他自彈自唱時，常在練習過程遇到三個核心阻礙：
1. **封閉和弦門檻高**：歌曲原調若出現 `F`、`Bm`、`Bb`、`F#m`、`C#m` 等大橫按（Barre Chords），初學者手指肌力不足容易按不響而中斷練習。
2. **變調夾（Capo）換算困難**：想配合自己音域升降 Key，或想透過夾 Capo 改彈簡單的 `C` 調、`G` 調開放指法時，不確定該夾在第幾格最省力。
3. **靜態純文字譜缺乏回饋**：網路上的傳統吉他譜僅有純文字，無法直接點擊查看簡化按法，也無法立即試聽替換後的和弦聲響是否自然。

### 2. 與 AI 討論後的技術可行性收斂
最初構想是做「輸入任意歌名就自動產生吉他譜並替換指法」的網站；但在與 AI 討論規格時釐清了兩項關鍵限制：
* **純前端環境與資安限制**：GitHub Pages 僅支援靜態前端託管，無後端伺服器；若在前端直接串接外部曲庫或 AI API，API Key 會直接暴露於瀏覽器原始碼中。
* **樂譜著作權問題**：商業歌曲的完整歌詞與曲譜受版權保護，不適合直接內建大量受版權保護的流行歌庫。

因此，我們將產品規格收斂並升級為 **「內建 5 首公版／經典練習曲 ＋ 支援使用者貼上任何網路雙行吉他譜自動解析轉換」** 的互動工作站，在單一 `index.html` 內完整實現自由轉調、智慧 Capo 建議與和弦簡化替換。

## 二、系統功能規格與實作對照表

本專案所有規格均與 `index.html` 實際功能 1:1 對應，無任何靜態假按鈕或未實作區塊：

| 功能模組 | 規格書設計目標 | 實際網頁互動實作細節 |
| :--- | :--- | :--- |
| **1. 曲目庫與貼譜解析器** | 內建公版範例歌，並支援使用者貼上、編輯與儲存自訂吉他譜 | 內建 5 首涵蓋 C、D、F、G 調的經典練習曲；提供彈出式編輯器支援 `[C]歌詞` 語法與 **「雙行吉他譜自動轉內嵌格式」** 演算法，並透過 `localStorage` 持久化保存於瀏覽器。 |
| **2. 十二平均律轉調系統** | 一鍵升降半音，全曲和弦與轉位低音自動換算 | 支援 `-1 半音`、`+1 半音` 與 `還原原調`，可自由切換 `#`（升記號）與 `b`（降記號）同音異名顯示，並支援分數和弦（如 `C/G`、`G/B`、`D/F#`）根音與低音同步轉調。 |
| **3. 智慧 Capo 建議引擎** | 自動評估夾哪一格 Capo 可以讓全曲指法最簡單 | 以 `evaluateCapoOption()` 統一掃描 Capo 0～9 格的指法難度權重（封閉和弦加權扣分、開放和弦加分），列出前 3 名最佳把位與預計消除的大橫按數，提供「一鍵套用」並同步顯示「實際音高」與「押弦指法」。 |
| **4. 封閉和弦簡化與自訂替換** | 將不會按的和弦自動或手動替換為簡易按法 | 提供琴弦撥桿式 **「一鍵簡化」** 開關，自動將大橫按替換為開放和弦（如 `F → Fmaj7`、`Bm → Bm7`、`Bb → Bbmaj7`、`F#m → F#m7`），並支援手動輸入自訂替換規則（如 `F → Dm7`），於譜面以松石綠標籤清楚標示原和弦。 |
| **5. 互動 SVG 指板與多把位切換** | 點擊任一和弦放大顯示指板圖，並可切換不同把位與試聽 | 頂部自動彙整「本曲指板總覽」，點擊卡片或譜面和弦即可連動下方大尺寸檢視器，切換 2～3 種不同按法（標準橫按／免橫按簡易四弦／開放替代），並觸發 `Web Audio API` 合成真實感六弦撥弦音效。 |
| **6. 練琴輔助與排版工具** | 提供實際彈唱所需的節拍、捲譜與檢視模式切換 | 內建 40–220 BPM 視覺與聲音節拍器、4 段速度自動捲譜、雙行對齊譜與 `[C] 行內簡譜` 切換、字體縮放（`A-` / `A+`）與一鍵複製轉調後譜面。 |

## 三、視覺美學與核心互動設計：「安靜的琴房」

### 1. 空間氛圍與色彩計畫
整體介面屏棄高飽和霓虹色，以夜晚木吉他練習室為靈感：
* **背景與材質**：採用暖調深木色底（`#12100e` 至 `#1a1713`），疊加極低透明度的內嵌 SVG `feTurbulence` 噪點濾鏡與木紋線性漸層，搭配吉他第 5 格單圓點、第 12 格雙圓點品位鑲嵌（Inlay Dots）分隔線。
* **色彩階層**：主文字使用溫潤暖白（`#ece4d6`），主強調色採用黃銅色（`#d4a24c`），輔助色採用低飽和松石綠（`#6d9b87`，專門標示 Capo 建議與簡化替換後的和弦）。
* **字體系統**：標題使用襯線體 `Fraunces` 與 `Cormorant Garamond`，正文使用 `Inter` 與 `Noto Sans TC`，和弦代號、指法編號與 BPM 則統一使用 `JetBrains Mono` 等寬字體。

### 2. 阻尼正弦波琴弦物理引擎 (`pluck`)
不依賴單調的 CSS 縮放或抖動，而是以 SVG `<path>` 二次貝茲曲線（`M x1 y1 Q cx cy x2 y2`）搭配共用單一 `requestAnimationFrame` 迴圈，實作真實的阻尼簡諧運動公式：
* **物理公式**：中點偏移量隨時間衰減 $	ext{displacement}(t) = A \cdot \sin(\omega t) \cdot e^{-\gamma t}$，約在 0.8～1.4 秒內自然靜止。
* **六處互動整合**：
  1. **頂部橫跨整頁琴弦**：滑鼠滑過時產生輕微水波擾動，點擊時大幅撥動並發出 E4 空弦泛音。
  2. **按鈕底弦回饋**：轉調、還原、套用 Capo、套用替換規則與試聽按鈕底部皆內嵌細弦，按下時同步撥動。
  3. **和弦卡與譜面 40ms 依序刷弦**：點擊和弦時，6 條弦由低音至高音每隔 40ms 依序震動，與 Web Audio 刷弦泛音完全同步（悶音弦 `✕` 保持靜止）。
  4. **大尺寸指板音高差異化震動**：第 6 弦（青銅粗弦）至第 1 弦（銀白細鋼弦）依實際音高設定不同振幅、頻率與衰減率。
  5. **轉調彎音（Pitch Bend）動畫**：升降半音時，調性顯示框下方的琴弦會先朝升降方向拉緊偏移，再釋放回彈震動。
  6. **琴弦撥桿開關**：切換「一鍵簡化」時，黃銅弦鈕滑過指板槽並將中間的琴弦撥向另一側震動。

## 四、Vibe Coding：與 AI 協作與反覆迭代紀錄

本專案透過多輪提示詞（Prompting）與 AI 反覆討論、測試與修正完成，以下為四個關鍵迭代階段：

### 第一階段：概念發想與規格邊界界定
* **問題發現**：最初希望輸入任何歌名就能自動出譜，但受限於純前端無後端保護 API Key 及樂譜版權限制。
* **AI 協作成果**：與 AI 討論後轉向「貼譜智慧工作站」模式，先確立轉調、Capo 試算、和弦簡化、SVG 指板圖、內建公版曲與 `localStorage` 自訂編輯六大核心規格。

### 第二階段：初版實作與「雙行譜自動轉換」補強
* **問題發現**：初版完成後測試發現，一般吉他手從網路複製的譜多為「上一行和弦、下一行歌詞」的空白對齊格式，若要手動逐字加上 `[C]` 中括號太費時。
* **AI 協作成果**：請 AI 在自訂譜編輯器中撰寫 `convertTwoLineSheetToBracket()` 解析演算法，自動判斷和弦行並依字元索引位置嵌入下一行歌詞中，大幅提升貼譜實用性。

### 第三階段：視覺重構（「安靜的琴房」）與物理琴弦互動升級
* **問題發現**：初版採用深藍底配高彩度按鈕，視覺較像一般後台工具，缺乏木吉他的樂器溫度與觸覺回饋。
* **AI 協作成果**：提出「安靜的琴房」設計規範，請 AI 全面換上暖黑木紋、黃銅與松石綠配色，重繪具玫瑰木底板、骨質上弦枕與粗細漸變琴弦的指板圖，並實作共用單一 `requestAnimationFrame` 的 `pluck()` 二次貝茲曲線琴弦震動引擎；同時改為局部更新機制 `selectAndStrumChord()`，避免點擊和弦時重繪整頁 DOM 而中斷正在震動的琴弦動畫。

### 第四階段：樂理指法校對與智慧 Capo 演算法一致性修正
* **問題發現**：檢視初版和弦資料庫時，發現 `Cm7` 點按指法不自然、`C#m` 缺少免大橫按的純三和弦按法、`C#` 與 `Db` 等同音異名和弦定義不一致，且未收錄的罕見延伸和弦會默默退回 `C` 和弦而無提示。
* **AI 協作成果**：
  1. 逐一校對修正 `Cm7`（標準三格封閉 `x35343` 與高音四弦 `xx1313`）、`C#m`（補齊四弦純三和弦 `xx6654` 並標明 `x42100` 為 `C#m7` 聲響）與 `Dbmaj7`（`xx3111`）。
  2. 建立 `ENHARMONIC_EQUIV` 同音異名映射表，讓 `#` 與 `b` 調共享完整按法；遇到未收錄的特殊延伸和弦時，於檢視器顯示明確的近似和弦代用提示。
  3. 將目前把位難度徽章與智慧 Capo 推薦統一交由 `evaluateCapoOption()` 計算，確保開啟「一鍵簡化」或切換不同按法時，推薦結果與狀態列完全一致。

## 五、快速操作與貼譜測試指南

1. **測試智慧 Capo 與一鍵簡化**：
   * 在左上角曲目選單選擇 **《生日快樂歌 Happy Birthday (F大調)》** 或 **《歡樂頌 Ode to Joy (D大調)》**。
   * 觀察左側「智慧 Capo 建議」自動計算出 **夾第 5 格（彈 C 調指法，無大橫按）** 或開啟 **「一鍵簡化」** 自動將 `F` 換成 `Fmaj7`、`Bm` 換成 `Bm7`。
2. **測試雙行吉他譜自動轉換**：
   * 點擊右上角 **「自訂 / 貼上吉他譜」**，在內容框貼上以下雙行格式並點擊 **「✨ 自動將雙行譜轉為 [和弦] 格式」**：
   ```text
   C        G/B      Am       Em
   深夜琴房 撥動琴弦 唱出心裡 那段想念
   F        C        Dm7      G
   換個簡單 替代指法 音樂依然 溫暖心田
   ```
   * 點擊「儲存並套用至譜面」，即可對新貼上的樂譜進行自由轉調、Capo 試算與刷弦試聽。
